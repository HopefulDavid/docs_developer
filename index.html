Vývojář

Dokumentace pro vývojáře

Osobní vývojářská dokumentace sjednocená podle tematických oblastí. Přehledy a navigace se skládají automaticky ze zdrojových souborů, aby zůstaly konzistentní i při dalším rozšiřování.

Oblasti

Oblast Stránek Záměr
AI 1 Nástroje a postupy pro práci s lokálními i vývojářskými modely umělé inteligence.
Verzování 15 Praktické postupy pro Git, větve, historii a běžnou správu repozitářů.
IDE 2 Nastavení a používání vývojových prostředí pro každodenní práci.
Programování 43 Vývojové platformy, jazyky, frameworky, balíčky a opakovaně použitelné postupy.
Databáze 5 Databázové systémy, dotazy a nástroje pro přístup k datům.
DevOps 1 Infrastruktura, automatizace a provozní postupy pro vývojářské prostředí.
Dokumentace 2 Nástroje a postupy pro tvorbu, převod a údržbu technické dokumentace.
Virtualizace 7 Kontejnery, lokální virtualizace, orchestrace a související správa prostředí.
Síť 2 Síťové technologie, přístupy, certifikáty a bezpečné propojení prostředí.
Operační systémy 3 Praktické poznámky k operačním systémům a jejich příkazovým nástrojům.
Grafika 1 Grafické nástroje, pracovní postupy a praktické tipy pro vizuální tvorbu.
Video 1 Nástroje a postupy pro nahrávání, střih nebo zpracování videa.
Komunikace 1 Nástroje a postupy pro týmovou komunikaci a organizaci práce.

Údržba

  • Aktualizace přehledů a navigace: npm run docs:generate.
  • Kontrola bez zápisu: npm run docs:check.
  • Build DocFX výstupu: npm run docs:build.
  • Historie změn: Změny.
